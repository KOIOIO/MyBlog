# Folio Promo Video

这是 Folio 个人博客约 30 秒宣传视频的可编辑制作目录。影片面向普通访客，以真实网站录屏为主体，采用“安静的知识空间”视觉方向，并使用年轻中性声旁白与同步字幕。

## 目录

- `raw/`：真实网站录屏片段
- `audio/`：旁白与背景音乐
- `graphics/`：标题卡、片尾卡及其他图形素材
- `output/`：带声音、无声音预览和验收截图
- `script.txt`：唯一的旁白时间线与字幕文案
- `shot-list.md`：按时间段对应的拍摄内容

## 目标导出设置

- 画布：1920x1080（16:9）
- 帧率：30 fps
- 视频编码：H.264，像素格式 `yuv420p`
- 音频编码：AAC
- 混音采样率：48 kHz
- 目标时长：30 秒（旁白建议 28–30 秒）
- 导出：启用 `+faststart`，便于网页播放

## 画面与字幕安全区

所有标题、网址和字幕放在移动端裁切安全区内：左右至少保留画布宽度的 10%，上下至少保留画布高度的 10%。字幕位于底部安全区，使用暖白或深墨色文字，并配深色半透明描边/底衬，确保静音播放时仍清晰可读。

## 声音与视觉基调

旁白使用自然、轻快但不过度广告化的年轻中性声；背景使用无歌词的轻盈 lo-fi 钢琴或木吉他，并将音乐压低以保持人声清晰。画面使用暖白、墨绿和少量灰蓝，搭配轻微纸张纹理、柔和缩放、淡入和光标轨迹。

录屏必须来自 `https://wwyhahablog.top/` 的公开页面，不得暴露管理员凭据或访客隐私。
