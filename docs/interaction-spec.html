Minimal Editorial Interaction System · 2026-09-29 · 状态：已冻结（实施分片唯一契约）

交互层不动视觉 token不动后端/路由/i18n禁重动画库

1摘要与现状诊断（批判）

视觉已完成「极简编辑风」重构，但交互模型仍是 Element Plus / md-editor-v3 的原生默认，等于「换了皮、没换瓤」。核心病灶：

  • 拖沓：el-dialog/el-drawer 默认 300ms 线性过渡，无 scale、无缓动层次，进出场一个速度；
  • 扁平：无按压反馈（按钮点下去毫无反应）、无 focus-visible 焦点环（键盘导航不可见）、hover 只有简单换色；
  • 换皮不换瓤：目录栏仍是 md-editor-v3 的静态列表高亮（只是把绿色改成了黑灰色），标签筛选仍是 el-radio-button 这个后台表单控件搬到前台，交互与最初版本完全一致——用户已明确指出这两处必须重构；
  • 无动效语言：无滚动显现、无阅读进度、无回顶、无骨架屏、主题切换硬切、二级评论展开靠 v-if 硬跳。

本规范依据三路并行调研（leerob / Vercel / Medium / Vitepress / Next.js docs / Linear / Stripe / shadcn / Radix / Tailwind / NN/g 等，源码级取参）冻结为可执行参数契约。所有参数均有来源；标「待实测」的项由实施分片在浏览器中校准。

2设计原则（交互宪法）

  1. 快速：120–200ms 为主，上限 300ms；按压/退场 80–120ms。退场总比入场快 40–60ms（「用完即走」）。
  2. 克制：只动 transform / opacity / 色值 / 阴影，禁 transition:all；不做 confetti、长 spring（≥400ms）、旋转、背景缩放等「为动效而动效」。
  3. 即时反馈：hover 150ms 内响应，按压 80ms 内响应；点击即答，不许延迟表演。
  4. 双主题一致：参数全复用，仅换色值；深色下阴影为 none（已定）。
  5. 可降级：prefers-reduced-motion: reduce 时所有动画/过渡坍缩为即时；reveal 内容默认可见（JS 失败不吞内容）。

4全局动效基座（Slice 1 专属）

4.1 关键帧（base.css）

  • kf-pop：0% scale(1) → 50% scale(1.15) → 100% scale(1)，时长 150ms，缓动 --ease-pop；用于点赞、chip 选中。
  • kf-shake：25% translateX(4px)；50% translateX(-4px)；75% translateX(4px)，300ms --ease-out，只播一次；用于表单校验失败。
  • kf-fade-up：from opacity 0 translateY(6px) → to 1/0，150–200ms --ease-out；用于错误文案、空态文案、新评论入场。
  • kf-pulse：opacity 1→.5，2s ease-in-out infinite；骨架屏（不做强光扫射 shimmer）。
  • kf-toc-flash：background var(--accent-weak) → 透明，300ms；目录点击确认。

4.2 reveal 指令（新增 web/src/directives/reveal.ts，main.ts 注册 v-reveal）

  • 块级元素进入视口触发：opacity 0→1 + translateY(16px)→0，200–250ms --ease-out；IntersectionObserver rootMargin 底部 -15%，once（触发后 unobserve）。
  • stagger：容器 v-reveal="{stagger:60}" → 子项 delay = 60ms × index，总级联 ≤240ms（子项上限 ~4–5 个，超出不继续加延迟）。
  • reduced-motion 或 JS 不可用：立即显示（指令挂载时若 IO 不可用直接加 is-revealed）。
  • 模板类型若被 vue-tsc 拦截，在 reveal.d.ts 声明 GlobalDirectives 即可。

4.3 全局 focus-visible

:focus-visible { outline: 2px solid var(--accent); outline-offset: 2px; }
/* 默认 :focus 不强制 outline；键盘导航可见即可 */

4.4 路由过渡（App.vue）

router-view 包 <transition name="page" mode="out-in">：进入 opacity 0→1 150ms --ease-out；离开 80ms 淡出。不做位移、不做 clip-path。

4.5 主题切换过渡

base.css：html.theme-switching, html.theme-switching *,...{ transition: background-color .25s var(--ease-out), color .25s var(--ease-out), border-color .25s var(--ease-out), box-shadow .25s var(--ease-out) !important; }；ThemeToggle（Slice 2）在 setAttribute 前后挂/摘该 class（300ms 后移除），图标加 200ms 轻微旋转/缩放换场。

6分域规范 B · 目录栏交互重构（重点域，Slice 2 · 用户点名）

现状批评：md-editor-v3 的 MdCatalog 只做了「滚动高亮 + 点击 smooth」，改色只是把绿高亮换成黑灰——交互模型与最初版本零差异。用户已明确不满意，本域必须重构感知交互，而非再打磨。
子交互目标行为参数
连续阅读进度指示条目录左侧 2px 竖线不再「定格在当前项」，而是随滚动在标题项之间连续移动：IO(rootMargin -20%/-60%) 判定 active 索引，按 (scrollY−headingTop)/(nextTop−headingTop) 插值出指示条 top（落在两标题之间时线性过渡）2px；accent；top 过渡 150ms --ease-out（插值区间内连续）
active 项双态指示条指向项：accent 文字 + weight 700；不用整行背景块color/weight 过渡 150ms
目录自动居中跟随active 项滚出目录可视区时，目录容器 scrollIntoView({block:'nearest'}) 保持可见（节流 ≤60ms/次）——长文目录不再「跟丢」节流 60ms
点击缓动 + 确认反馈点击项：页面平滑滚动（html scroll-behavior smooth；或 rAF 缓动 ≤300ms）；正文标题 scroll-margin-top:80px 防 sticky 遮挡；被点项播 kf-toc-flash 300msscroll-margin-top 80px；flash 300ms
首载 stagger 入场目录项按序 fade-up 进入（仅首载一次）150ms / 间隔 60ms
hover 提示目录项 hover 右侧滑入「跳转」图标（opacity 0→1 + translateX(2px)）150ms --ease-out

实现说明：优先保留 MdCatalog 承担锚点/active 判定，在其外层加进度指示条与自动居中（读 md-editor DOM 类名 md-editor-catalog-*）；若 DOM 测量不可行，降级为自研 IO 方案。不得改变文章正文结构与锚点。

明确不引入：折叠/树形展开（改文章结构语义）、整行背景块高亮（旧体验）、序号数字、弹跳动画。
